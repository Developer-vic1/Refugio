# Imágenes originales del sitio

Siete imágenes creadas con imagegen integrado. PNG originales conservados en output/imagegen (fuera de Git). Las copias finales WebP mantienen la composición y se optimizaron para publicación web, con máximo 1600 px y calidad 87. No representan instalaciones, personas, donaciones ni expedientes reales. Las vistas las identifican como ilustrativas.

## inicio-paseo-v2

Archivo final: `public/assets/img/inicio-paseo-v2.webp`.

Prompt original:

Wide landscape 1536x1024 editorial photo-style illustration for a new animal refuge website. One playful black and white mixed breed adult dog, bright curious eyes, walking toward viewer through soft meadow grass at warm morning light. Nature, hope, candid lively movement, refined warm cinematic photography look, forest green foliage, honey sunlight, light cream negative space on left for HTML headline. No cat, no golden retriever, no text, no letters, no logos, no people, no tags with writing. This is an illustrative generated visual, not a documented rescue case. Natural anatomy, exceptionally warm and tasteful nonprofit visual design.
